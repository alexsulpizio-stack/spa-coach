SPA COACH PHONE v0.8.0

BROWSER TESTING:
1. Run start_phone.bat on the PC.
2. Open the displayed Wi-Fi address on your phone.
3. Browser mode cannot reliably notify you after the browser is closed.

REAL ANDROID REMINDERS:
1. Open ANDROID_BUILD_README.txt.
2. Build the Android project for development, or install the signed APK from GitHub Releases.
3. Open Spa Coach > Settings > Enable Phone Reminders.
4. Allow notifications when Android asks.
5. Use Send Test Notification to verify it.

Once the APK is installed, the PC is not needed for normal use.

UPDATES:
Settings > Check for Updates downloads the release inside Spa Coach, verifies its SHA-256 digest, and then opens Android's installer. Approve the per-app “install unknown apps” setting when Android requests it.
