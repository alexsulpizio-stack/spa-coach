# Spa Coach

Spa Coach is a local-first hot-tub water testing and maintenance coach for the browser and Android.

- `source/` contains the canonical web app, Android project, tests, and documentation.
- `source/lib/version.js` is the single source of application version information.
- `source/android/app/src/main/assets/www/` is generated by Gradle and must not be edited.
- `.github/workflows/build-android.yml` tests and publishes signed release APKs from the tracked source tree.
- `update.json` is the live OTA manifest generated after a release is published.

See [`source/README.md`](source/README.md) for features and development instructions.
